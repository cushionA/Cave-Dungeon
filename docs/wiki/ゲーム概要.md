# ゲーム概要

## コンセプト

| 項目 | 内容 |
|------|------|
| ジャンル | 3Dダンジョン探索アクションRPG |
| 主人公と同行者 | プレイヤーが操作する骸骨騎士と、AIで行動するシスター |
| ターゲット | 探索とアクションが好きな人。召喚魔物の編成やシスターのAI設定も楽しめる |
| プラットフォーム | PC・一人用 |
| プレイ時間 | 本編約20時間を目安に試作で調整 |

## コアループ

1. 骸骨騎士とシスターで3Dダンジョンを進み、少数の召喚仲間と近道や次の区画を探す。
2. NPC魔物の依頼や物語イベントを終える。シスターの呼びかけに応じるのは、イベントで指定されたNPC本人やその仲間。
3. 次の区画に合わせて、人数とコストの上限内で魔物を選ぶ。同じ種類を複数体呼ぶこともできる。
4. 魔物溜まりや指定ボス戦で追加の援軍を呼ぶ。味方が側道を押さえる間に、騎士は奥の敵へ踏み込める。
5. 戦闘を終えたら探索編成に戻り、新しく開いた道や以前見つけた分岐に向かう。

## 探索で出会った魔物との共闘

普段はお気に入りの仲間と少人数で歩き、大きな戦闘では助けてきた魔物たちに持ち場を任せる。プレイヤーは援軍の到着後も騎士を操作し、自分で隙を見つけて攻める。召喚魔物は、初めて呼んだときから作者が用意した行動で戦う。プレイヤーは指揮官を通じて魔物に簡単な指示を出す。

### シスターの支援とAI設定

| 方式 | 対象 | MP消費 | 説明 |
|------|------|--------|------|
| 連携ボタン | カジュアル〜全員 | シスターのMPを消費 | ボタン1つで支援魔法を発動 |
| AIルール自動発動 | やり込み勢 | CT消化済みなら無料 | 条件ルールで最適タイミング自動発動 |

- **カジュアル層**: AIカスタムしなくても連携ボタンで十分遊べる
- **やり込み層**: 条件付きAIルールを組んでクールタイム管理を最適化
- **エンドコンテンツ**: ボスラッシュ・タイムアタックでAI最適化の真価

### シスターの条件付きルール

プレイヤーが詳細な行動ルールを設定できるのはシスターだけ。

- **条件**: 「敵HPが30%以下」「プレイヤーHP50%以下」「特定属性の敵」等
- **行動**: 「追撃」「回復魔法」「バフ」「防御優先」等
- **優先度**: ルール間の優先順位を設定
- **モード**: 最大4モード + 自動切替条件 + ショートカット手動切替

## キャラクター構成

| 種別 | 編成 | 説明 |
|------|--------|------|
| プレイヤー | 1人 | 骸骨騎士を操作する |
| 常駐仲間 | 1人 | シスター。行動ルールを設定して連携する |
| 召喚する魔物 | 編成コストの範囲内 | NPCイベントで解放された魔物をシスターが呼ぶ。同じ種類を複数体呼ぶ場合も、1体ごとにコストがかかる |
| 混乱敵 | 0〜3 | 混乱魔術で一時味方化（パーティ枠外） |

マップで戦う野生の魔物は通常の戦闘相手。二周目以降は、対象に指定されたボスも条件を満たせばシスターの召喚候補に加わる。各個体のコスト、増援の規模、戦闘中に呼び直せるタイミングは調整事項。

現行の召喚管理は固定2枠、パーティ上限4人。イベント解禁や戦闘別の編成は今後の設計に含まれる。[召喚システム設計](../../designs/systems/SummonSystem.md)

## メカニクス概要

### 戦闘
- 武器切替（最大2スロット）、コンボ分岐、チャージ攻撃
- パリィ/ジャストガード、ガードブレイク
- 7属性統一（斬撃/打撃/刺突/炎/雷/聖/闇）
- 状態異常蓄積モデル

### 成長
- レベルアップ + 能力値振り分け（STR/DEX/INT）
- 装備: 武器(右手) / 盾(左手) / コア(1スロット)
- 片手持ち(盾併用) ⇔ 両手持ち(盾無効、武器スキル使用可)
- 装備重量比率でアクション性能変動
- 魔法・能力は探索で拾得（スキルツリーではない）

### 探索
- Additive Scene Loadingによるシームレスエリア遷移
- セーブポイントで回復 + セーブ + ファストトラベル
- AbilityFlag獲得でバックトラック報酬解放
