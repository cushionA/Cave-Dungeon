# System: LevelUpSystem
Section: 1 — MVP

## 責務
経験値蓄積、レベルアップ判定、能力値振り分けUI。レベルアップ時にステータスポイントを獲得し、プレイヤーがビルド方向を決定する。

## 依存
- 入力: EnemySystem（経験値獲得）、DataContainer
- 出力: レベルアップ、能力値更新、OnLevelUp/OnExpGainedイベント

## 共通能力値の契約（DF-01）

プレイヤー・敵・仲間・召喚キャラは、同じ登録入力から共有データを生成する。

| データ | 意味 | 更新責任 |
|--------|------|----------|
| CharacterBaseStats | 素体の最大HP/MP/SP/アーマー、回復設定、属性攻防、移動設定、素の能力フラグ、基礎6能力 | CharacterInfoから登録時に転記する再計算原本 |
| CharacterGrowth | レベルと追加配分した6能力 | 成長処理・読み込み・敵設定などの入力元が共通更新APIへ渡す |
| CharacterVitals / CombatStats / MoveParams / CharacterFlags | 行動・被弾・移動・UI・AIが使う値 | 登録・導出処理と各ゲーム処理 |

基礎6能力と配分6能力は別々に保持し、合計は共有データの `GetAttributes` から取得する。基礎最大HP/MPは、素体の基礎VIT/MNDを含めて作者が設定する値であり、基礎6能力を追加しただけで再加算しない。既存実装の成長式「配分VIT×10を最大HPへ、配分MND×5を最大MPへ」を共通計算へ移す。STR/DEX/INT/ENDによる攻防・重量・回復等の式はDF-02/03で扱う。

新規登録は導出した最大値まで満タンにし、基礎値・成長入力・利用値・各システムの登録を済ませてから登録通知を発行する。成長の再反映は毎回基礎値から計算し、現在HP/MP/SP/アーマーと位置を維持する。最大値を下げた場合だけ現在値を新上限へ制限し、増加による無料回復は行わない。成長入力と利用値の書き込み後に能力値変更を通知する。

プール再取得はCharacterInfoから同じ初期値を作り直す。成長を保持して再生成する呼び出し元は、保存した成長入力を明示して登録する。敵に経験値・ポイント配分を必須にせず、共通の成長入力だけを受け付ける。

LevelUpLogicは経験値・未配分ポイント・配分操作・保存を担当し、`Growth` で共通入力を公開する。`GameManager.ApplyCharacterGrowth` が共有データへの反映口となる。経験値報酬・成長UI・SaveManagerへの登録・シスターの自動レベル同期は未接続であり、この登録契約の完成とは区別する。`statCaps` は従来どおり追加配分値の上限で、基礎能力込みの上限へ変更しない。

## コンポーネント構成
| コンポーネント | 責務 | MonoBehaviour? |
|--------------|------|---------------|
| LevelManager | 経験値・レベル管理 | No (GameManager保持) |
| StatAllocator | 能力値振り分けロジック | No |
| LevelUpUI | 振り分けUI | Yes |

## レベルアップフロー
```
敵撃破 → OnExpGained(expAmount)
    → LevelManager.AddExp(amount)
    → 累計EXP >= 次レベル必要EXP
    → レベルアップ！
    → statPoints += pointsPerLevel (例: 3ポイント)
    → OnLevelUp発火
    → セーブポイントでStatAllocatorを使って振り分け
```

## 能力値振り分け
```
セーブポイント → 「レベルアップ」メニュー
    → 未使用statPointsを表示
    → STR / DEX / INT / VIT / MND / END に振り分け
    → 確定 → ステータス再計算 → EquipmentSystem再計算トリガー
```

### 能力値→ステータス影響（Common_Section1 §6準拠）
- STR → 物理攻撃力, 光攻撃力(部分), 最大重量上限
- DEX → 物理攻撃力(部分), 闇攻撃力(部分)
- INT → 火攻撃力, 雷攻撃力, 光(部分), 闇(部分), 最大MP
- VIT → 最大HP, 物理防御
- MND → 最大MP(部分), 魔法防御, 状態異常耐性
- END → 最大スタミナ, スタミナ回復速度, 最大重量上限(部分)

## 経験値テーブル
- EXP必要量はAnimationCurveで定義（レベルごとの必要EXP曲線）
- バランスシートで調整

## 機能分解
| 機能名 | 説明 | テスト種別 | 優先度 |
|--------|------|-----------|--------|
| 経験値蓄積 | 敵撃破時のEXP加算 | EditMode | High |
| レベルアップ判定 | 累計EXP vs テーブル | EditMode | High |
| 能力値振り分け | ポイント割り当てとステータス再計算 | EditMode | High |
| 振り分けUI | セーブポイントでの振り分け画面 | PlayMode | Medium |
| ステータス再計算 | 能力値変更→全ステータス更新 | EditMode | Medium |

## 設計メモ
- 振り分けはセーブポイントでのみ可能（レベルアップ即時ではない）
- リスペック（振り直し）は対象外（Section3以降で検討）
- 仲間AIのレベルアップはプレイヤーと自動同期（独立振り分けなし）
